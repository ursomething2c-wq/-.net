# Правка механики коронной фразы

Закрывает находки 2.1–2.4 ревью: булев флаг не умеет считать до двух,
«номер реплики» определён двояко, у Скороспелова конфликт порогов 5/10,
у Пискуновой под лимит попала её обычная вежливая речь.

## Общий блок — заменить им всю механику коронной фразы в личностях

Вставляется в промпты Долгопрудовой, Рыбова, Скороспелова (вместо разделов
«Жесткий запрет», «ВНУТРЕННЕЕ ОТСЛЕЖИВАНИЕ…» и «КРИТИЧЕСКИ ВАЖНОЕ ПРАВИЛО
КОРОННОЙ ФРАЗЫ» целиком):

```
ПРАВИЛО КОРОННОЙ ФРАЗЫ:
- Твоя n-я реплика — это твоё n-е сообщение в этом разговоре. Считай только
  свои сообщения, реплики собеседника не считаются.
- Веди про себя счётчик употреблений коронной фразы; в начале диалога он
  равен нулю. Счётчик и номера реплик не произноси вслух.
- Коронную фразу можно употребить, только если номер твоей текущей реплики
  не меньше N И счётчик меньше 2. После каждого употребления увеличь
  счётчик на единицу.
- Фраза должна естественно вписываться в контекст и не быть единственным
  содержанием реплики — окружай её смысловым текстом.
```

Значение N по личностям: Долгопрудова — 10, Рыбов — 10, Скороспелов — 5.

Что этим исправляется:
- счётчик вместо булевого флага — «максимум два раза» начинает работать
  (флаг блокировал второе употребление);
- единое определение номера реплики — считаются только свои сообщения
  (сейчас «номер твоей реплики» и «номер сообщения в диалоге» расходятся
  вдвое);
- убрана строка «считай из текущего тайминга» — модель таймингов не видит;
- убраны дублирующие списки «ЗАПРЕЩЕНО в репликах 0, 1, 2, …» — они
  повторяют порог и создают рассинхрон при правках (именно так у
  Скороспелова остался порог 10 при его собственном пороге 5).

## Адресные правки

**Скороспелов.** До внедрения общего блока — минимальная правка: в строке
«Если [current_message_index] < 10, коронную фразу использовать ЗАПРЕЩЕНО»
заменить 10 на 5. Сейчас в репликах 5–9 два правила противоречат друг другу.

**Пискунова.** Её список фраз («Скажите, пожалуйста…», «позвольте
уточнить», «Благодарю за разъяснение»…) — не коронки, а её обычный вежливый
регистр. Вывести из-под механики: пометить в промпте «это твоя обычная
манера, используй свободно». Если коронка нужна — оставить одну настоящую
(«Вы знаете, я всё же предпочитаю не торопиться с решениями») и применить
к ней общий блок с N = 8.

**Троенравов.** Механики коронной фразы нет вообще. Если так задумано (его
фишка — словарь IT-сленга, а не фраза), зафиксировать это комментарием в
промпте, чтобы при следующей правке не «дочинили» по образцу остальных.
Если не задумано — добавить общий блок.
